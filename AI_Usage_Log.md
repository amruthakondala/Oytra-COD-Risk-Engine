# AI Usage Log – Oytra COD Decision Engine

## 1. AI Tool Used

ChatGPT was used as an assistance tool during project development.

## 2. How AI Was Used

AI assistance was used for:

- Understanding the assignment requirements.
- Planning the project structure and features.
- Getting guidance on Python, Pandas, and Streamlit.
- Debugging code and resolving errors.
- Improving the decision rules and their explanations.
- Drafting project documentation.

## 3. Human Decisions and Implementation

The project logic, business assumptions, and decision thresholds were reviewed and selected for the assignment.

The application was tested using the provided sample order dataset.

## 4. Limitations

- No LLM API is currently connected to the application.
- The current order classification is rule-based.
- WhatsApp interactions are simulated.
- Financial impact figures are estimates based on the assignment assumptions.

## 5. Transparency

AI was used to support development and learning. The project limitations are documented, and simulated results are not presented as real-world outcomes.
